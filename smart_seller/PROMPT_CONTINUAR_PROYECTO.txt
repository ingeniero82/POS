PROMPT PARA CONTINUAR EL PROYECTO SMART SELLER POS

---

CONTEXTO:

Soy un desarrollador migrando un sistema POS de Flutter Desktop a React + Node.js + PostgreSQL.

PROYECTO ORIGINAL:
- Nombre: Smart Seller POS v2.0
- Tecnología: Flutter Desktop + SQLite
- Problema: Flutter Desktop es inmaduro, ejecutable no funciona en clientes
- Decisión: Migrar a React + Node.js + PostgreSQL

NUEVO PROYECTO:
- Tecnología: React + TypeScript + Node.js + Express + PostgreSQL
- Arquitectura: Cliente-Servidor (3 capas)
- Modelo: Web App (PWA) - Funciona en navegador, offline con Service Workers
- Enfoque: Aprendizaje paso a paso, no crear todo de una vez

ARQUITECTURA ACTUAL (Flutter - a migrar):
- 9 tablas: users, products, sales, sale_items, customers, groups, inventory_movements, company_config, clients
- 5 roles: admin, manager, supervisor, cashier, maintenance
- 30+ permisos granulares
- Sistema de impuestos: IVA (0%, 5%, 19%), IpoConsumo, Bolsas plásticas
- Productos por unidad y peso (balanzas)
- Servicios: Auth, Permissions, Tax Calculation, Reports, Print, Scale

ARQUITECTURA NUEVA (React + Node.js):
- Frontend: React 18 + TypeScript + React Router + React Query + Material-UI
- Backend: Node.js + Express + TypeScript + Prisma ORM
- Base de Datos: PostgreSQL
- Autenticación: JWT
- Offline: Service Workers + IndexedDB
