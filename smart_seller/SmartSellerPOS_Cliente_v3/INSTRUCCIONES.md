# Smart Seller POS - Instrucciones de Instalación

## Instalación Rápida
1. **Ejecutar como Administrador**: `INSTALAR_COMPLETO.bat`
2. **Solo dependencias**: `INSTALAR_DEPENDENCIAS.bat`
3. **Instalación básica**: `INSTALAR.bat`

## Requisitos del Sistema
- Windows 10 o superior
- Arquitectura 64-bit
- 4GB RAM mínimo
- 2GB espacio libre en disco

## Solución de Problemas
Si el ejecutable no abre:
1. Ejecutar `INSTALAR_DEPENDENCIAS.bat` como administrador
2. Verificar que Windows Defender no bloquee la aplicación
3. Revisar `SOLUCION_PROBLEMAS_EJECUTABLE.md`
