## 📖 CÓMO ESTUDIAR CADA LECCIÓN

### **ANTES de la Lección:**
1. ✅ Lee el título y objetivos
2. ✅ Revisa qué conceptos previos necesitas
3. ✅ Ten tu entorno listo (VS Code abierto)

### **DURANTE la Lección:**
1. ✅ **Escucha activamente** - No solo oyes, entiendes
2. ✅ **Toma notas** - Escribe lo importante
3. ✅ **Haz preguntas** - Si algo no está claro, pregunta
4. ✅ **Sigue el código** - Escribe junto conmigo

### **DESPUÉS de la Lección:**
1. ✅ **Repasa tus notas** - 10 minutos de repaso
2. ✅ **Haz la práctica** - No la copies, entiéndela
3. ✅ **Experimenta** - Cambia cosas y ve qué pasa
4. ✅ **Pregunta dudas** - Si algo no quedó claro

---

## 💻 CÓMO PRACTICAR

### **Nivel 1: Copiar y Entender**
- Copia el código exacto
- Ejecútalo y ve que funciona
- Lee cada línea y entiende qué hace
- **Pregunta:** "¿Por qué esta línea hace esto?"

### **Nivel 2: Modificar**
- Cambia valores (números, textos)
- Agrega una línea más
- Quita algo y ve qué pasa
- **Pregunta:** "¿Qué pasa si cambio esto?"

### **Nivel 3: Crear desde Cero**
- Con los conceptos aprendidos
- Crea algo similar pero diferente
- Sin copiar, solo usando lo aprendido
- **Pregunta:** "¿Puedo hacer esto de otra forma?"

---

## 🐛 CÓMO MANEJAR ERRORES

### **Cuando Tengas un Error:**

1. **NO TE FRUSTRES**
   - Los errores son normales
   - Todos los programadores tienen errores
   - Es parte del aprendizaje

2. **LEE EL MENSAJE DE ERROR**
   - El error te dice qué está mal
   - Busca palabras clave
   - Copia el mensaje completo

3. **BUSCA EL PROBLEMA**
   - Revisa el código línea por línea
   - Compara con el ejemplo que funcionó
   - Verifica mayúsculas/minúsculas

4. **PREGUNTA**
   - Muestra el error completo
   - Muestra tu código
   - Explica qué intentabas hacer

## 📝 TOMAR NOTAS EFECTIVAS

### **Qué Anotar:**

✅ **Conceptos nuevos**
- "Node.js es JavaScript en el servidor"
- "useState guarda datos que cambian"

✅ **Sintaxis importante**
- Cómo se escribe
- Ejemplo de código

✅ **Errores comunes**
- Qué error tuviste
- Cómo lo solucionaste

✅ **Preguntas**
- Lo que no entendiste
- Para preguntar después

### **Cómo Anotar:**

```
❌ MAL:
"Node.js es bueno"

✅ BIEN:
"Node.js = JavaScript que corre en el servidor
- Permite crear servidores web
- Usa el mismo lenguaje que el frontend
- Ejemplo: app.get('/ruta', función)"
```

## ❓ CUÁNDO Y CÓMO PREGUNTAR

### **Pregunta INMEDIATAMENTE si:**
- No entiendes un concepto
- El código no funciona y no sabes por qué
- Algo no tiene sentido para ti
- Quieres saber "por qué" algo es así

### **Cómo Preguntar Efectivamente:**

❌ **MAL:**
"Esto no funciona"

✅ **BIEN:**
"Tengo este error: [mensaje completo]
Este es mi código: [código]
Estaba intentando: [objetivo]
Ya intenté: [lo que probaste]"
