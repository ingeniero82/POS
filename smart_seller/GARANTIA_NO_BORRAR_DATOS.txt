MANTENIMIENTO AUTOMATICO - GARANTIAS:

1. SOLO OPTIMIZA (VACUUM + ANALYZE)
   --------------------------------

   - ANALYZE: Mejora rendimiento, NO borra
   - Es como desfragmentar un disco duro
   - NO elimina registros de ninguna tabla

2. FUNCIONES QUE NUNCA SE EJECUTAN AUTOMATICAMENTE:
   -------------------------------------------------
   ❌ cleanOldSales() - NO se ejecuta automáticamente
   ❌ cleanOldInventoryMovements() - NO se ejecuta automáticamente
   ❌ Cualquier función que borre datos - NO se ejecuta automáticamente

   ✅ Ventas - NUNCA se borran
   ✅ Inventario - NUNCA se borran

4. CODIGO VERIFICADO:
   -------------------
   El código solo ejecuta:

   - NO ejecuta funciones de limpieza
   - NO ejecuta funciones que borren datos
