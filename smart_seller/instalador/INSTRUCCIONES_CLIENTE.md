# 📦 Instrucciones de Instalación - Smart Seller POS

## Para el Cliente Final

### Requisitos del Sistema
- ✅ Windows 10 o Windows 11 (64-bit)
- ✅ 4GB de RAM mínimo
- ✅ 2GB de espacio libre en disco
- ✅ Conexión a Internet (solo para instalar dependencias)

---

## 🚀 Instalación Paso a Paso

### Paso 1: Ejecutar el Instalador

1. **Localizar el archivo:** `SmartSellerPOS_Setup_v2.0.exe`
2. **Hacer clic derecho** sobre el archivo
3. Seleccionar **"Ejecutar como administrador"**
   - Si aparece una advertencia de Windows, hacer clic en **"Más información"** → **"Ejecutar de todos modos"**

### Paso 2: Seguir el Asistente

1. **Bienvenida:** Hacer clic en "Siguiente"
2. **Carpeta de instalación:** 
   - Por defecto: `C:\Program Files\Smart Seller POS`
   - Puede cambiarla si lo desea
   - Hacer clic en "Siguiente"
3. **Accesos directos:**
   - Marcar las opciones deseadas (Escritorio, Menú de inicio)
   - Hacer clic en "Siguiente"
4. **Instalación:**
   - El instalador copiará los archivos
   - **Se instalará automáticamente Visual C++ Redistributable** si es necesario
   - Esto puede tomar 2-5 minutos

### Paso 3: Finalizar

1. Al finalizar, marcar **"Ejecutar Smart Seller POS"** si desea iniciar la aplicación
2. Hacer clic en **"Finalizar"**

---

## ✅ Verificación de Instalación

Después de instalar, verificar:

1. **Acceso directo en el escritorio** (si se seleccionó)
2. **Menú de inicio:** Buscar "Smart Seller POS"
3. **Iniciar la aplicación** y verificar que se abre correctamente

---

## 🔧 Solución de Problemas

### El instalador no inicia

**Solución:**
- Ejecutar como administrador (clic derecho → "Ejecutar como administrador")
- Verificar que Windows Defender no esté bloqueando el archivo
- Desactivar temporalmente el antivirus

### Error: "No se puede instalar Visual C++ Redistributable"

**Solución:**
1. Descargar manualmente desde: https://aka.ms/vs/17/release/vc_redist.x64.exe
2. Instalar manualmente
3. Ejecutar el instalador de Smart Seller POS nuevamente

### La aplicación no inicia después de instalar

**Solución:**
1. Verificar que Visual C++ Redistributable esté instalado
2. Reiniciar el equipo
3. Ejecutar la aplicación como administrador (solo la primera vez)
4. Verificar que Windows Defender no esté bloqueando la aplicación

### Error: "Falta DLL" o "No se puede encontrar el módulo"

**Solución:**
1. Reinstalar Visual C++ Redistributable
2. Ejecutar Windows Update
3. Contactar al soporte técnico

---

## 📞 Soporte Técnico

Si tiene problemas durante la instalación:

1. **Capturar pantalla** del error
2. **Anotar** el mensaje de error exacto
3. **Verificar** la versión de Windows:
   - Presionar `Windows + R`
   - Escribir `winver` y presionar Enter
4. **Contactar** al equipo de soporte con esta información

---

## 🗑️ Desinstalación

Para desinstalar la aplicación:

1. Ir a **Configuración de Windows** → **Aplicaciones**
2. Buscar **"Smart Seller POS"**
3. Hacer clic en **"Desinstalar"**

O desde el menú de inicio:
1. Buscar **"Smart Seller POS"**
2. Clic derecho → **"Desinstalar"**
