DOCUMENTACION DE ARQUITECTURA - SmartSeller POS v2.0

INFORMACION GENERAL

Identificacion del Sistema:
- Nombre: SmartSeller POS (Point of Sale)
- Version: 2.0 Final
- Arquitectura: Cliente-Servidor (Local)
- Patron: Model-View-Controller (MVC)
- Tecnologia: Flutter/Dart + SQLite
- Fecha: Diciembre 2024

ARQUITECTURA GENERAL DEL SISTEMA

El sistema SmartSeller POS v2.0 utiliza una arquitectura de tres capas principales:

CAPA 1: INTERFAZ DE USUARIO
Esta capa contiene todas las pantallas y componentes visuales del sistema.
- Pantallas principales (Login, POS, Inventario, Clientes, etc.)
- Widgets personalizados (botones, campos de texto, tarjetas)
- Sistema de navegacion entre pantallas

CAPA 2: LOGICA DE NEGOCIO
Esta capa maneja toda la logica y reglas del sistema.
- Controladores que gestionan el estado de cada pantalla
- Servicios especializados (autenticacion, impresion, base de datos)
- Middleware de seguridad y validacion

CAPA 3: ACCESO A DATOS
Esta capa se encarga de almacenar y recuperar informacion.
- Base de datos SQLite local
- Modelos de datos estructurados
- Operaciones de lectura y escritura

MODELOS DE DATOS:

BASE DE DATOS

TABLAS PRINCIPALES:

Tabla Users (Usuarios):
- id: Identificador unico
- username: Nombre de usuario
- password: Contrasena encriptada
- full_name: Nombre completo
- role: Rol del usuario (admin, vendedor, mantenimiento)
- is_active: Estado activo/inactivo

Tabla Products (Productos):
- id: Identificador unico
- name: Nombre del producto
- price: Precio de venta
- cost: Precio de costo
- stock: Cantidad en inventario
- type: Tipo (unidad o peso)
- category_id: Categoria del producto

Tabla Customers (Clientes):
- id: Identificador unico
- document_type: Tipo de documento
- document_number: Numero de documento
- full_name: Nombre completo
- email: Correo electronico
- phone: Telefono

Tabla Sales (Ventas):
- id: Identificador unico
- customer_id: Cliente asociado
- user_id: Usuario que realizo la venta
- total: Total de la venta
- subtotal: Subtotal sin impuestos
- tax: Impuestos aplicados
- payment_method: Metodo de pago
- sale_date: Fecha de la venta

CONCLUSION

SmartSeller POS v2.0 es un sistema de punto de venta profesional construido con tecnologias modernas y una arquitectura robusta. Su diseno modular permite facil mantenimiento y extension de funcionalidades, mientras que su sistema de seguridad garantiza la proteccion de datos y operaciones.

La arquitectura de tres capas (presentacion, logica de negocio, acceso a datos) asegura la separacion de responsabilidades y facilita el desarrollo, testing y mantenimiento del sistema.

El sistema esta disenado para ser escalable, seguro y facil de usar, cumpliendo con los estandares de la industria y las regulaciones fiscales colombianas.
