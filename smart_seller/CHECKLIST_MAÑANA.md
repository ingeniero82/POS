## 💻 INSTALACIÓN DE SOFTWARE

### **1. Visual Studio Code (Editor de Código)**
- [ ] Descargar: https://code.visualstudio.com/
- [ ] Instalar
- [ ] Verificar que abre correctamente

### **2. Node.js (Runtime de JavaScript)**
- [ ] Descargar: https://nodejs.org/ (versión LTS)
- [ ] Instalar
- [ ] Verificar instalación:
  ```bash
  node --version
  ```
  Debe mostrar algo como: `v20.x.x` o `v18.x.x`

- [ ] Verificar npm (viene con Node.js):
  ```bash
  npm --version
  ```
  Debe mostrar algo como: `10.x.x`

### **3. Git (Control de Versiones)**
- [ ] Descargar: https://git-scm.com/download/win
- [ ] Instalar
- [ ] Verificar instalación:
  ```bash
  git --version
  ```
  Debe mostrar algo como: `git version 2.x.x`

### **4. PostgreSQL (Base de Datos) - OPCIONAL para mañana**
- [ ] Descargar: https://www.postgresql.org/download/windows/
